### 4. Studio Progression System (COMPLETE)
**Files:** `lib/progression.ts`

**Level System:**
- Level 1-2: Garage - Actor + Director only
- Level 3-4: Writer, Cinematographer, Editor unlock
- Level 5-6: Sound, Composer, VFX unlock
- Level 7+: Producer, full marketing tools

**Unlock Gates:**
- `maxActors`: increases with level (3 → 8+)
- `maxSupporting`: supporting roles (1 → 3+)
- `availableRoles`: roles unlocked by level
- `marketingUnlocked`: level 6+
- `testScreeningsUnlocked`: level 4+
- `festivalSubmissionUnlocked`: level 7+

**Office Upgrades:**
- Garage → Small: $150,000
- Small → Medium: $500,000
- Medium → Large: $1,500,000

### 5. Industry Events System (COMPLETE)
**Files:** `lib/industry-events.ts`

**Event Types:**
- Writer Strike (90 days) - blocks writers, 1.5x cost
- Actor Burnout (60 days) - specific actors unavailable
- Union Action (30 days) - 1.2x crew costs
- Festival Invite (45 days) - +5 critic, +2 reputation
- Streaming War (60 days) - +10 audience
- Weather Delay (14 days) - filming delays
- Test Screening Leak (7 days) - random buzz
- Awards Buzz (90 days) - +8 critic, +3 reputation

**Event System:**
- ~5% chance per week
- Multiple events can be active
- Effects stack (salary modifiers, boosts)
- Events auto-expire after duration

### 6. Multi-Stage Pipeline Types (COMPLETE)
**New ProductionPhase values:**
- `planning` - Script development, Writer hiring
- `preproduction` - Cinematographer, locations, schedule
- `filming` - Scene planner, principal photography
- `postproduction` - Editor, Sound, VFX
- `marketing` - Campaign strategy, release planning

**Stage Durations:**
- Planning: 8 weeks
- Preproduction: 6 weeks
- Filming: 10 weeks
- Postproduction: 8 weeks
- Marketing: 6 weeks

### 7. Stage Decision System (COMPLETE)
**Files:** `lib/stage-decisions.ts`

Each stage has 1-2 possible decisions at 50% progress:

**Planning Decisions:**
- Script depth (deep revision vs fast draft)
- Source material (hot IP vs original vs public domain)

**Preproduction Decisions:**
- Production plan (practical vs VFX vs compressed vs premium locations)

**Filming Decisions:**
- On-set challenges (overtime vs move on vs reshoot)
- Actor conflicts (replace vs accommodate vs director handle)

**Postproduction Decisions:**
- Post focus (VFX shots vs sound vs edit time vs balanced)

**Marketing Decisions:**
- Strategy (festival premiere vs viral vs traditional vs limited)

## 🏗️ ARCHITECTURE NOTES

**Modular Design:**
- All new systems are in separate files
- Easy to add more events (`industry-events.ts`)
- Easy to add more decisions (`stage-decisions.ts`)
- Progression curve tunable (`progression.ts`)

**Backward Compatibility:**
- Old save files will need migration
- Consider adding version field to GameState
- Provide defaults for missing fields

**Performance:**
- Event generation is throttled (5% chance)
- Auto-save still on 100ms debounce
- Stage progression uses intervals (300ms ticks)

## 📈 BALANCING NOTES

**Progression Curve:**
- Levels 1-3: Learn basics (actors, director, writer)
- Levels 4-6: Professional tier (full crew)
- Levels 7+: Master tier (all features)

**Budget Scaling:**
- Micro: Learn mechanics
- Low: Standard projects
- Mid: Requires good reputation
- High: End-game prestige

**Decision Impact:**
- Low risk: Safe, small gains
- Medium risk: Meaningful tradeoffs
- High risk: Big swings, budget-sensitive
