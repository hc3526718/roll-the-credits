# ROLL THE CREDITS OWNER DESIGN BRIEF

**Genre**: Creative tycoon  
**Primary Inspiration**: Game Dev Tycoon  
**Aesthetic**: 2D/2.5D isometric diorama, cartoon/vector, readable silhouettes  
**Core Fantasy**: Filmmaker building a company — **not a production spreadsheet**

---

## CORE LOOP

Research → Choose project → Genre×Format → Concept → Scale → Build team → Allocate priorities → Live incidents → Finish → Release strategy → Critic+audience → Revenue/rep → Post-mortem → Research/hire/upgrade → Next.

---

## PROJECT DEFINITION

**Project = Topic × Genre × Format × Scale × Audience × Platform**

### Early Formats (Prototype)
- Social Video
- Short Film
- Music Video
- Commercial
- Micro-doc

Mid/late formats unlock later. **Don't reveal all optimal combos** — teach via reports.

---

## FIVE PRODUCTION STAGES

Each stage has **three linked sliders** sharing a 100-point pool:

### 1. Planning
- Script/Story
- Storyboard/Previz
- Budget/Schedule

### 2. Recruitment
- Casting
- Crew
- Locations

### 3. Filming
- Cinematography
- Performance
- Production Design

### 4. Post-Production
- Editing
- Sound/Score
- VFX/Grade

### 5. Marketing
- Trailer/Campaign
- Press
- Distribution/Release

---

---

## PRODUCTION INCIDENTS

Real choices during filming/post that change production variables:
- Always include **unique FREE option**
- Always include **extremely cheap option**
- Pause production/clock while modal open
- Never soft-lock when over budget

---

## RESEARCH & PROGRESSION

**Research = Production Lab → House Pipeline** (like GDT engines)

Unlock:
- New formats
- New genres
- New talent tiers
- Production capabilities
- Distribution channels

---

## VISUAL IDENTITY

**Orthographic 3/4 isometric**
- Layered 2D sprites in pseudo-3D rooms
- Cutaways
- Small animations
- NO AI-generated art — code-drawn only

**UI Principles**
- Large text
- Cards
- Clear bars
- **No dense spreadsheets**
- **Constant interaction rule** — rarely idle

---

## PROTOTYPE PRIORITIES (§40)

Build these FIRST for the addictive core loop:

1. ✓ Garage 2.5D environment (isometric diorama)
2. ✓ Project selection screen
3. ☐ Genre × Format (Topic×Genre×Format×Scale)
4. ☐ **Five production stages** with **three linked sliders** each
5. ☐ Staff/talent library (unique, no multi-select bugs)
6. ☐ Live production animation in miniature studio
7. ✓ Critic + audience scores
8. ✓ Revenue calculation
9. ☐ Post-mortem report (GDT-style learning)
10. ✓ Research / Production Lab screen
11. ✓ Basic studio upgrade (garage → first office)

**Then expand**: Talent contracts, festivals, franchises, departments, etc.

---

## NON-NEGOTIABLES

1. **Fast** — snappy, responsive
2. **Not a spreadsheet** — visual, tactile, delightful
3. **2.5D identity** — recognizable art style
4. **Scarcity early** — constrained choices teach optimal play
5. **Failure teaches** — post-mortems explain what went wrong
6. **Every employee has a reason** — unique stats/chemistry matter
7. **Environment evolves** — garage → studio → lot → empire

---

## FINAL FEEL

**"I made this."**

The player should feel proud of their projects, their studio, and their creative journey.
